# Simple PDF Editor

PDFに文字や簡単な図形を重ねて追記する、Windows向けの簡易デスクトップアプリです。
元PDFは直接変更せず、編集状態は `.pdfedit` として保存し、必要なタイミングで編集済みPDFを書き出します。

## 主な機能

- PDFを開いて1ページずつ表示
- ページ移動、ズーム
- 文字、四角形、楕円、直線、矢印の追加
- 追加オブジェクトの選択、移動、リサイズ、削除
- 右側パネルで色、線幅、文字サイズなどを編集
- `.pdfedit` 形式で編集状態を保存・再オープン
- 注釈を焼き込んだPDFを別名で出力

## セットアップ

Python 3.11以降を想定しています。

```powershell
python -m pip install -e .
```

## 起動

```powershell
python -m simple_pdf_editor
```

または、インストール後に以下を実行します。

```powershell
simple-pdf-editor
```

## 使い方

1. `開く` でPDFまたは `.pdfedit` を開きます。
2. ツールバーから `文字` や図形ツールを選び、PDF上をクリックまたはドラッグします。
3. 作成したオブジェクトはクリックで選択し、ドラッグで移動できます。
4. 選択中のオブジェクトは角ハンドルでリサイズできます。
5. `保存` で `.pdfedit` を保存し、`PDF出力` で編集済みPDFを書き出します。

## ショートカット

- `Ctrl+O`: 開く
- `Ctrl+S`: 編集状態を保存
- `Ctrl+E`: PDF出力
- `Ctrl+C`: コピー
- `Ctrl+V`: 貼り付け
- `Delete`: 削除
- `Ctrl+Z`: 元に戻す
- `Ctrl+Y`: やり直す
